# milo

milo airidian, the personal henchman. he navigates support systems on
the boss's behalf: chat widgets, portals, email, discord, slack,
forums, and the phone tree. dispatched, never autonomous; polite,
never pushy; on behalf, never as.

one repo, two parts, the same shape as his sister prixie:

- `website/` — the site (milo.kloudie.dev). react + tanstack start +
  tailwind, the prose that explains him.
- `backend/` — the engine. deno + hono + supabase, the mission
  machinery that does the work. see `backend/README.md` for the full
  contract: the walks, the coax engine, the follow-up cadence, the
  gates, and what is honestly not built yet.

`docs/research/` holds the seams the engine rides: what prixie lends,
what livekit dials.
